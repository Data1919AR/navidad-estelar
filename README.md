# Navidad Estelar · Cómic fan

Flipbook del cómic fan **Navidad Estelar** (Diarios de Star Trek): se lee online pasando las páginas y se descarga en PDF.

Producción de fans, gratuita y sin ánimo de lucro, sin relación oficial con Paramount ni CBS. Star Trek y sus personajes y marcas pertenecen a sus propietarios.

Pasador de páginas: StPageFlip (licencia MIT, ver `lib/LICENSE`). Tipografía: Oswald (licencia OFL).
